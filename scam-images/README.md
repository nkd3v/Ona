# Scam example images

Drop copies of new scam images here (PNG, JPEG, WebP, GIF or BMP) and restart the
bot. Uploads that look like these images are deleted automatically. Re-saved,
resized, or recompressed copies still match. Heavily cropped or mirrored copies do not.

The images from the "MrBeast crypto casino" (wispwin.com and fapwin.com) scam are
built into `scam_filter.py`, so they do not need to be added here.
